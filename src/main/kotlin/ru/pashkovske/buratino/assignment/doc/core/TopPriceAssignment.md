Параметры команды:
- `instrumentId` - идентификатор инструмента
- `direction` - направление: покупка или продажа
- `oneStepOver` - строго лучше среди остальных заявок или не хуже

Выставляет заявку по "лучшей" цене в стакане.
- Для продажи - максимальная цена, которая меньше всех остальных заявок;
- Для покупки - минимальная цена, которая больше всех остальных заявок.

`refresh` - обновляет заявку по "лучшей" цене в стакане.
